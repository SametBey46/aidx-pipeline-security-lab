# Security policy

Please do not open public issues containing credentials, customer data, internal addresses, or a working attack chain against a live system.

For a vulnerability in a deployment based on this lab, contact the system owner privately and include:

- affected component and version;
- minimal, redacted reproduction details;
- expected and observed behavior;
- remediation ideas, if available.

This repository is intentionally limited to a local, non-destructive training demonstration.
